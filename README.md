# Tam Nguyen

Personal portfolio site — [tamng-02.github.io](https://tamng-02.github.io)

## About

Business & IT student at HWR Berlin, currently working at SAP Signavio. Originally from Odenwald, Germany — lived in Madrid, Berlin, and Shanghai.

## Stack

Plain HTML/CSS, no frameworks. Uses:
- [Leaflet.js](https://leafletjs.com/) for the interactive journey map
- [OpenStreetMap](https://www.openstreetmap.org/) tiles
- Google Fonts (Nunito)

## Local preview

Open `index.html` directly in a browser — no build step needed.
